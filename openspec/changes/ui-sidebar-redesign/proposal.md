# UI 侧边栏布局重构（ui-sidebar-redesign）

## Why

当前主界面是单列布局 + 9 个工具栏按钮横排的网格（`App.tsx` 5571 行巨石组件），入口平铺、缺少分组导航和层次感。用户已用 UI 工具产出三页设计稿（数据列表 / 图表分析 / 数据维护，附于本 change 的 `design-ref/` 目录），要求按设计稿重构页面与按钮布局。用户明确约束：**配色风格保留当前不变**（当前为 violet/blue/pink 渐变 + 毛玻璃拟态，设计稿中的青绿色系仅作布局参考、不采用）。

## What Changes

- **应用外壳重构**：单列 + 按钮网格布局 → 固定左侧边栏（260px，分组导航：数据管理/报告/工具/同步/危险操作，底部用户信息）+ 顶栏（页面标题、全局搜索、通知铃铛、用户头像）。现有 9 个工具栏入口 1:1 迁移到侧边栏分组，无功能删减。
- **统计卡片**：3 张卡片（总记录数 / 检验指标种类 / 最后更新）按设计稿重排（图标块 + 标签 + 大数值 + 趋势徽章），数据口径不变。
- **数据列表页**：分类下拉 + 按日期×指标透视表按设计稿卡片化重排，新增客户端分页（页码 + 共 N 条记录信息）。
- **图表分析页**：新增时间范围筛选（7天/30天/90天/全部）+ 分类下拉；图表区改为 2 列图表卡片网格（每指标一卡：标题 + 变化徽章 + 最高/最低/平均/当前摘要），并新增综合雷达卡（类别内指标最新值归一化对比）。
- **数据维护页**：按设计稿改为 2×2 功能启动卡片（检验指标维护 / Excel 数据管理 / 报告导入管理 / 云端同步）+ 危险区（删除全部）；卡片下方**保留**现有可编辑记录表格（RecordTable）与带恢复功能的变更记录列表，并按设计稿视觉语言重新设计（用户已确认）。
- **新增真功能**（用户已确认，不做装饰性死按钮）：顶栏全局搜索（实时过滤当前页表格/图表数据）；通知铃铛（下拉面板：最近变更记录 + 云同步状态）。
- **移动端**（用户已确认）：小屏下侧边栏收进汉堡菜单抽屉，顶栏与内容区自适应堆叠，功能与桌面端一致。
- **配色约束**：沿用当前 violet/blue/pink 渐变、毛玻璃、rose 危险、emerald 成功的配色体系；设计稿的间距、圆角、卡片结构、布局层级照搬。
- **开发流程**：在新建分支上开发（不直接在 main 上改）；完成后进行全面回归测试（含既有单测与逐按钮验证）。

## Capabilities

### New Capabilities

- `ui-shell`: 应用外壳 — 侧边栏导航（含全部 9 个功能入口与用户菜单）、顶栏、全局搜索、通知中心、统计卡片、页签导航、移动端抽屉适配。
- `ui-data-list`: 数据列表页 — 分类筛选、日期×指标透视表、客户端分页与记录数信息。
- `ui-chart-analysis`: 图表分析页 — 时间范围筛选、分类筛选、逐指标图表卡片网格、综合雷达卡。
- `ui-data-maintenance`: 数据维护页 — 功能启动卡片、危险区、可编辑记录表格、变更记录与恢复。

### Modified Capabilities

（无 — 现有 `attachment-upload` / `attachment-view` / `attachment-storage` 等能力的行为需求不变，本次仅重排承载它们的界面；附件上传/预览等交互行为全部保留。）

## Impact

- **代码**：`src/app/App.tsx`（布局重排，外壳与页面结构大改）、`src/app/components/RecordTable.tsx`、`RecordChart.tsx`、`src/styles/theme.css`（补充布局用语义 token）；新增侧边栏/顶栏/搜索/通知等组件文件。
- **不受影响**：后端 `api/`、`report-parser/`、Supabase 数据流、导出/导入/云同步/附件的业务逻辑与 localStorage key 约定（`health_*_v1`、`__userId` 后缀）。
- **测试**：`App.export.test.tsx`、`MedicalReportImportDialog.test.tsx` 需随 DOM 结构调整修正选择器；逐按钮手工/E2E 验证清单见 tasks.md。
- **风险**：Radix Tabs 当前为非受控（`defaultValue="table"`），重构后改为受控以支持搜索/通知联动跳转；需保证撤销/恢复栈与云同步触发点（`triggerAutoBackup`）不被遗漏。
